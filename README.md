# CS2 AI Chat Assistant

Помощник для игрового чата **Counter-Strike 2**: по нажатию горячей клавиши читает последние сообщения игроков с экрана, генерирует ответ через языковую модель (локальную или OpenAI) и вставляет его в поле чата от твоего имени.

> Скрипт **не читает память игры, ничего не инжектит и не даёт преимущества в бою**. Он работает как человек: смотрит на экран и вводит текст с клавиатуры.

## Как это работает

```
[F8] → открыть чат → скриншот области чата → OCR (Tesseract)
     → фильтр: только сообщения игроков (системные пропускаются)
     → LLM (Ollama / OpenAI) → ответ
     → вставка в поле чата (Enter нажимаешь ты сам)
```

## Возможности

- Чтение чата через OCR (русский и английский)
- Пропуск системных сообщений (вход/выход игроков, покупки, бомба и т. д.), ответ только на сообщения игроков
- Подстройка под тон собеседника: дружелюбным отвечает по-дружески, токсичным даёт отпор
- Работает с локальной моделью через [Ollama](https://ollama.com) (бесплатно, без интернета) или через OpenAI API
- Защита от повторов: не копирует фразы из чата и не повторяет свои прошлые ответы
- Не отвечает на собственные сообщения
- Поддержка кириллицы (текст вставляется через буфер обмена)
- По умолчанию текст только вставляется в поле чата, отправка за тобой (`AUTO_SEND = False`)

## Требования

- Windows 10/11
- Python 3.10+
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) с языками **Russian** и **English**
- [Ollama](https://ollama.com) (или ключ OpenAI API)
- CS2 в режиме **«Полноэкранный в окне»**

## Установка

**1. Клонируй репозиторий и установи библиотеки**

```bash
git clone https://github.com/<твой-логин>/<название-репозитория>.git
cd <название-репозитория>
pip install -r requirements.txt
```

**2. Установи Tesseract**

Скачай установщик с [страницы UB-Mannheim](https://github.com/UB-Mannheim/tesseract/wiki). На экране «Choose Components» открой **Additional language data** и отметь **Russian**. Путь по умолчанию: `C:\Program Files\Tesseract-OCR\tesseract.exe`.

Проверка:

```bash
"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs
```

В списке должны быть `eng` и `rus`.

**3. Установи модель**

Вариант A, Ollama (локально, бесплатно):

```bash
ollama pull qwen2.5:3b     # лёгкая, для слабых ПК
# или
ollama pull qwen2.5:7b     # умнее, но медленнее
```

Вариант B, OpenAI:

```bash
setx OPENAI_API_KEY "sk-..."
```

После этого перезапусти консоль и поставь в скрипте `LLM_BACKEND = "openai"`.

**4. Настрой игру**

- Режим отображения: **Полноэкранный в окне**
- Чат открывается на `Y` (общий) или `U` (командный). Если у тебя другие клавиши, поменяй `CHAT_KEY`

## Калибровка

Нужно один раз подогнать область чата под твоё разрешение и HUD.

1. Зайди на карту (например, Deathmatch) и напиши в чат пару сообщений.
2. Запусти командную строку **от имени администратора**.
3. Выполни:

   ```bash
   python cs2_ai_chat.py --calibrate
   ```

4. За 5 секунд переключись в игру (Alt+Tab) и открой чат клавишей `Y`.
5. Скрипт сохранит `chat_area.png` (что захвачено) и `debug_last.png` (что видит OCR), а в консоль выведет распознанный текст.

Если текст не читается:

| Проблема | Что менять |
|---|---|
| В кадре лишнее сверху | Увеличь второе число в `CHAT_REGION_REL` |
| Чат обрезан снизу | Увеличь четвёртое число (высота) |
| Чат обрезан справа | Увеличь третье число (ширина) |
| Текст слипается, много пятен | Увеличь `OCR_THRESHOLD` (170, 190) |
| Буквы тонкие или пропадают | Уменьши `OCR_THRESHOLD` (130, 110) |

`CHAT_REGION_REL` задаётся в долях экрана: `(слева, сверху, ширина, высота)`.

## Запуск

```bash
python cs2_ai_chat.py
```

| Клавиша | Действие |
|---|---|
| `F8` | Прочитать чат и вставить ответ в поле ввода |
| `Enter` | Отправить сообщение (нажимаешь ты сам) |
| `F9` | Выйти из скрипта |

Запускай консоль **от имени администратора**, иначе перехват горячих клавиш может не работать.

## Настройки

Все параметры находятся в начале `cs2_ai_chat.py`:

| Параметр | Описание |
|---|---|
| `HOTKEY` / `EXIT_HOTKEY` | Клавиши запуска и выхода |
| `CHAT_KEY` | `y` (общий чат) или `u` (командный) |
| `AUTO_SEND` | `True`: отправлять сразу. `False`: только вставить текст |
| `LLM_BACKEND` | `"ollama"` или `"openai"` |
| `OLLAMA_MODEL` | Имя модели из `ollama list` |
| `CHAT_REGION_REL` | Область чата в долях экрана |
| `OCR_THRESHOLD` | Порог яркости текста (120–190) |
| `LINES_TO_READ` | Сколько последних сообщений передавать модели |
| `MY_NICK` | Фрагмент твоего ника, чтобы бот не отвечал сам себе |
| `PERSONA` | Стиль и характер ответов |

### Свой стиль ответов

Поведение бота задаётся блоком `PERSONA`. Можно сделать его вежливым, шутливым, молчаливым или жёстким. Для небольших моделей (3B) лучше писать короткие чёткие правила и добавлять примеры «сообщение → ответ».

## Решение проблем

| Проблема | Решение |
|---|---|
| Хоткей не срабатывает | Запусти консоль от имени администратора |
| `Нет связи с LLM` | Запусти Ollama и проверь `ollama list` |
| OCR выдаёт мусор | Сделай `--calibrate`, проверь `chat_area.png` и `debug_last.png`, подгони область и порог |
| Бот отвечает на свои сообщения | Впиши в `MY_NICK` кусок ника, который OCR читает стабильно |
| Бот повторяет одни и те же фразы | Упрости `PERSONA`, добавь разнообразные примеры или попробуй модель побольше (`qwen2.5:7b`) |
| Текст вставляется не в чат | Проверь `CHAT_KEY` и что окно CS2 активно |
| Ответ слишком долго генерируется | Возьми модель поменьше или используй OpenAI |

## Безопасность и правила

- Скрипт использует только скриншоты экрана и эмуляцию нажатий клавиш. Он не взаимодействует с процессом игры и не трогает её память.
- Valve не поддерживает автоматизацию чата. Использование на свой страх и риск.
- Многие серверы запрещают ботов в чате, а за спам и токсичность можно получить мут (communication ban) от Valve или бан от администрации сервера.
- Оставляй `AUTO_SEND = False` и не жми `F8` слишком часто.
- Не добавляй чтение памяти игры и инжект DLL: это уже риск VAC-бана.
- Проект не связан с Valve и Counter-Strike и не одобрен ими.
